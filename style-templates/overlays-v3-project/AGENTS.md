# Template instructions

Follow the root workspace guide and this template's DESIGN.md. Copy this template
into a video project before editing. Read the root style-templates/README.md for required assets.
Use the root HyperFrames skills. Lint, preview, and inspect rendered frames after
modifying a composition. All publishing requires the user's authorization.

This template is the overlays-project graphics-only pass (4K, transparent/alpha,
two-tier tier-1/tier-2 system) with the confirmed v3 "What We'll Cover" agenda
box-grid built in. Everything in `index.html` beyond the CSS system and the
`agendaBox()` helper is placeholder demo content and demo timestamps — replace
it with the real script and retime every beat against the project's own
transcript word timestamps. Never reuse the demo timestamps as real anchors.
